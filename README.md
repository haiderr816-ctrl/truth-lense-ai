Truth Lens is an AI-powered web application designed to fight misinformation and digital fatigue. By leveraging advanced Natural Language Processing, it helps users analyze news headlines, social media messages, and articles for bias, logical fallacies, and factual consistency.
​🚀 Key Features
​Semantic Analysis: Uses the Google Gemini API to understand the deeper meaning and intent behind text.
​Bias Detection: Identifies emotional manipulation and aggressive tones in reporting.
​Reliability Scoring: Provides a 0-100% confidence meter for every analyzed claim.
​Minimalist UX: A clean, distraction-free interface built for rapid fact-checking on the go.
​🛠️ Technical Stack
​Frontend: HTML5, CSS3 (Tailwind-inspired minimalist design)
​Logic: JavaScript (ES6+)
​AI Engine: Google Gemini API
​Version Control: Git & GitHub
​Hosting: Vercel
​📈 Why It Exists
​In a world of information overload, misinformation spreads faster than facts. Truth Lens acts as a personal digital shield, empowering users to make decisions based on data rather than emotional triggers. This project demonstrates my ability to integrate modern AI APIs with a clean, user-centric interface.
